01 Philosophy

How I think about design.

01

Clarity over decoration

Enterprise users open the same screen hundreds of times. Every element has to earn its place by making the next decision easier.

02

Understand the workflow first

I start with the business process — who does what, in what order, with which data — before drawing a single screen.

03

Design with the build in mind

Knowing HTML, CSS and how data is structured lets me design things that can actually ship, and prototype them when a static mockup isn't enough.

04

Use AI as a collaborator

I use Claude AI and vibe coding to explore ideas faster, pressure-test flows and turn designs into working prototypes — while keeping the judgement human.

02 Process

My design process.

  1. 01

    Understand

  2. 02

    Structure

    Information architecture, roles and permissions, user flows and edge cases.

  3. 03

    Sketch

    Low-fidelity wireframes to agree on layout and logic before visuals.

  4. 04

    Design

    High-fidelity UI, components and a consistent visual system in Figma.

  5. 05

    Prototype & Build

    Clickable prototypes and front-end builds with HTML, CSS, Tailwind and AI tooling.
